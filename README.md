# 240 Rubu’

A single-page tracker for reviewing a completed Qur'an hifz, one rubu' at a time.

- **Passes**: four sweeps of checkpoints over the 240 rubu', each twice as fine as the last (1 → 1,5 → 1,3,5,7 → all 8 per juz).
- **Steps**: step schedules over whole juz — a 12-step Simple ladder, the anchored / rotating / balanced spaced schemes, and capped runs — with a merged-cell graph of which juz each step recites.
- Score every rubu' A (clean), B (hesitated), C (opened the mushaf). Scores and progress are stored in the browser only.

Open `index.html` directly, or use the hosted page. No build step, no dependencies beyond Google Fonts.
